# Personal Website - Qeisya Dwi Hermawan

Website profil pribadi yang dibuat sebagai tugas praktik mata kuliah **Pemrograman Internet** — Program Studi Pendidikan Sistem dan Teknologi Informasi, Universitas Pendidikan Indonesia Kampus Purwakarta.

---

## Deskripsi

Website ini merupakan halaman profil pribadi yang dibangun menggunakan HTML dan CSS. Tampilan menggunakan tema warna lavender yang dikombinasikan dengan warna ungu.

---

## Halaman

- **Home** — Halaman utama berisi perkenalan singkat dan daftar mata kuliah yang sedang dipelajari
- **About** — Profil lengkap, data diri, hobi, dan riwayat pendidikan
- **Project** — Daftar project yang pernah dikerjakan beserta ringkasan tabel portofolio
- **Contact** — Form kontak untuk mengirim pesan
- **Skill** — Daftar kemampuan teknis dan non-teknis beserta tingkat penguasaan

---

## Teknologi

- HTML5
- CSS3

---

## Cara Menjalankan

1. Clone atau download repository ini
2. Buka file `index.html` menggunakan browser
3. Navigasi antar halaman menggunakan menu di bagian atas
